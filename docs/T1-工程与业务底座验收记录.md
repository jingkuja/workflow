## 运维边界

- PostgreSQL 和内部 API 不映射宿主机端口。
- `data/files` 与 PostgreSQL 命名卷独立于无状态应用容器。
- `NOTIFICATION_SEND_ENABLED=false` 时 Worker 不发送发件箱通知；配置真实
  Webhook 并完成业务联调后再开启。
- 剩余磁盘低于 `DISK_WARN_PERCENT` 时就绪检查告警，低于
  `DISK_REJECT_PERCENT` 时拒绝新的本地文件。
