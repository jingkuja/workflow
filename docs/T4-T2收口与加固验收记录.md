## 1. 本次交付

- MCP 业务工具全部通过 `WorkflowApiClient` 调用内部 API；API 使用原始 Bearer
  Token 二次校验身份和角色。
- Compose 不向 MCP 容器注入 `POSTGRES_*`，业务 `DATABASE_URL` 被内存 SQLite
  占位值替代。
- API 成功/失败 JSON 返回 `request_id`；稳定错误包含错误码、用户消息、修复建议
  和空的或真实可用的 `next_actions`。
- `get_workflow_dashboard` 提供阶段/积压、今日和本周审核通过量、35—40 目标差额、
  一次通过率、优先任务、最近驳回、阻塞、失败任务/通知和人员负载。
- 项目、本人任务和待审核中心支持分页、稳定排序；项目支持状态、负责人、优先、
  导入批次、关键词和时间过滤。
- 项目详情返回源文件、提交/审核版本与追加式审计时间线。
- 员工可用 `report_task_blocker` 幂等上报本人未结束任务阻塞；老板使用
  `list_operational_issues` 查询阻塞及失败后台任务/通知。
- `WAITING_FOR_FILMING` 明确为当前正常终态，审核通过后不返回任何 T3 后续动作。
- 完成部署、升级、回滚、备份、恢复、人员配置和故障处理手册。
